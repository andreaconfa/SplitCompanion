# Changelog

## 1.2.0-rc.6-homeassistant

- Generate the initial setup code automatically and show it in the App Log tab.
- Remove the manual setup-code option; old values no longer block startup.
- Keep 30-minute expiry, single use and failed-attempt limits. Configured instances
  never generate another setup code.

## 1.2.0-rc.5-homeassistant

- Initial Home Assistant App package for amd64 and aarch64.
- Persistent storage, protected first-administrator setup and automatic backups.
- English and Italian UI, configurable server default currency.
