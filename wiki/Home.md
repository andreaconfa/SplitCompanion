# Split Companion documentation

Install and operate your own private Split Companion instance on a Linux server.
The application container includes server and web/PWA. HTTPS remains under your control.

No managed cloud account is required. Initial setup creates an administrator;
that administrator creates the other users. The native iOS companion connects
to the same backend, but its source is not included in this server/web release.
